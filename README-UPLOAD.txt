BEYOND EARTH - نسخة جاهزة لـ GitHub Pages

ارفع محتويات هذا المجلد (وليس المجلد نفسه) إلى جذر مستودع GitHub. لازم يكون index.html بجوار الملفات الأخرى ومجلد photos.

ثم GitHub: المستودع > Settings > Pages > Build and deployment > Deploy from a branch > Branch: main > Folder: /(root) > Save.

مهم: هذا إصدار جديد مبني على الملفات التي أرسلتها الآن، ويحتوي بيانات الموقع والصور الجديدة، بالإضافة إلى ملفات الجلسة والغرفة ثلاثية الأبعاد التي كانت موجودة في الملفات السابقة. لا ترفع ملف ZIP إلى المستودع؛ فك الضغط أولاً وارفع كل المحتويات.
